# Morphing sticky game header and dual LQIP placeholder storage

**Status:** Accepted

VaporStats prioritizes a unified, scroll-responsive game details page where the main hero card itself acts as the sticky header (`position: sticky; top: 3.5rem`), transitioning its layout and constituent components as the user scrolls into a fully compact, single-line stuck state.

To prevent layout shifts and eliminate blank image flashes across both expanded and compact states:
1. **Dual LQIP Storage**: SQLite stores precomputed inline base64 placeholders for both the full landscape header image (`apps.header_lqip`) and the compact square icon (`apps.icon_lqip`). Placeholders are generated via Bun 1.4 native image processing (`Bun.Image`).
2. **Transitional Square LQIP**: Until scheduled ingestion backfills Steam Community icon hashes (`apps.icon_hash`), the interim square placeholder is generated by downscaling the full header image to a 32×32 square without cropping, preserving the full image content in the reduced bitmap.
3. **Asset Upgrade**: Once `icon_hash` is ingested, the compact header renders Steam's official 1:1 Community icon directly.
4. **Scroll-Driven Morphing**: Rather than docking a disconnected secondary bar, the primary hero card shrinks padding and collapses secondary details while crossfading the header image into the square icon, using parent `overflow-anchor: none` to prevent scroll-anchoring oscillation. The scroll animation starts as soon as the top of the hero reaches the sticky boundary (`top: 3.5rem`), executing in two overlapping phases:
   - **Phase 1 (0% to 60% progress)**: Secondary content (description, developer/publisher metadata, and lifecycle table) fades out and collapses height.
   - **Phase 2 (40% to 100% progress)**: Container padding compresses from full card padding to compact single-row padding (`px-4 py-2`), landscape artwork morphs and crossfades into the 32×32 square asset (Community icon or resized LQIP), and the title and release date align into a single line.

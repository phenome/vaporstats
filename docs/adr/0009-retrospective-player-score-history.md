# Reconstruct historical player scores without rewriting recorded history

VaporStats reconstructs earlier Current Player Scores using the existing score formula with verified anchors and whole evidence buckets from the same review population. The reconstruction retains provenance to the later observation that supports it; it does not prorate evidence, add full-coverage or event-completeness gates absent from the formula, or rewrite recorded rows. When newer review evidence runs out, the last supported estimate remains the estimate; zero-review buckets or elapsed time alone do not manufacture a new score.

Historical Monthly Score Comparisons use the currently eligible group and prefer recorded historical scores, using reconstructed values only when a recorded score is missing. Resolution is limited by available monthly granularity, and unsupported missing evidence stays missing. Reconstructions do not create rank snapshots and do not change ADR008’s independent rolling-90-day Now eligibility policy (250 actual reviews globally, 50 in filtered groups) or the distinction between Current Player Score and Lifetime Approval: filtered lifetime approval for Top Rated All Time must use its compatible population, without a compatibility-assuming histogram fallback.

# Trace each media claim to its supporting observations

A citation can identify the right game and article while supporting only part of a sentence. Extraction records independently checkable Media Observations, and synthesis references those observations so each claim can retain its own citations and any qualification that changes its meaning. An optional phrase such as “at PC launch” is sufficient when supported by the article. A publication date alone cannot establish the build played.

A discovery filter requires evidence for the characteristic as displayed. Evidence from an earlier state can support a historical observation. Broadening it to a general tag requires positive evidence for the broader claim.

Each ingestion checks observation references, game identity and required qualifications. Unsupported claims are omitted individually and the reason is recorded. If no supported Overview statement survives, the synthesis is refused. A definite editorial omission or refusal does not trigger a paid retry.

An explicit refresh collects unresolved observations in the [editorial follow-up document](../evaluations/media-unsure-entries.md). Human amendments apply to the cited observation and evidence version on subsequent processing. Human verification is optional. The same evidence rules apply to existing publication candidates, reusing extractions wherever they preserve the necessary evidence and scope.
